วิธีใช้งาน
1. แตกไฟล์ ZIP
2. เปิด VS Code > File > Open Folder > เลือกโฟลเดอร์ naklua-website
3. เปิด index.html เพื่อแก้ไขโค้ด
4. ดับเบิลคลิก index.html เพื่อดูเว็บไซต์ในเบราว์เซอร์

ไฟล์ index.html รวม HTML, CSS และ JavaScript ไว้ในไฟล์เดียว
ภาพพื้นหลังอยู่ที่ assets/naklua.png
แก้หัวข้อเมนูได้ในตัวแปร slides ภายในส่วน script
ต้นแบบนี้เขียนขึ้นโดยอ้างอิงรูปแบบการจัดวางและการเคลื่อนไหวจาก Dish Orbit Carousel ไม่ใช่ซอร์สโค้ดต้นฉบับของคอมโพเนนต์
